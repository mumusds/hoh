# UX 与交互规格

## 单一命令语义，按界面提供入口

`CommandService` 接收规范化意图；CLI/TUI/Web 不各写一套流程。统一的是语义，不要求菜单、斜杠与 Shell 一一对应。

Shell：`hoh`、`hoh -p <text>`、`hoh attach [run_id]`、`hoh web`、`hoh doctor`；通用 --help/--version。支持 --output text|json|stream-json、--detach、--project、--resume <run_id>。--resume 为 -p 或 attach 的限定选项，不新建 resume 子命令。多 run 时无 TTY 必须给 id，禁止选错最近会话。

TUI 高频 `/plan` `/build` `/auto` `/team` `/model` `/status` `/resume` `/help`。其它命令由 `/` 模糊选择器/设置页发现，初版不做大量一级命令。`/plan` 是进入 HoH Plan 模式，不是调用某个底座同名权限模式。斜杠转给底座必须显式选择目标，防止命名冲突。

## 模式与执行状态正交

Plan、Build、Auto 是意图模式；RUNNING、PAUSED、BLOCKED 是任务生命周期。Plan 可以写规格文档和非产品原型工件，不允许未经批准实施产品代码；切回 Auto 也不能清空既有阻塞。进行中的 Build 收到 /plan：先登记模式变更，阻止新写任务，等待当前安全点，界面显示 pending mode change，不假称立即完成。

## 默认 Workspace

顶部：项目名、mode、run、当前baseline。中间：用户/Commander对话与工程活动摘要，重要决策有依据和影响。底部：输入框，响应式 statusline。团队摘要可折叠，避免常驻巨型仪表盘挤压对话。

状态栏始终优先显示：mode、当前阶段/任务、已验收需求n/m、阻塞/issue。其次Git分支/候选、运行时间、预算。聚焦Agent时才显示该Agent模型/上下文；未知是“未知”，不是0。保存 minimal/standard/custom 配置。

## 视图

Workspace 默认；Team 只看分角色状态卡；Focus 查看某一执行完整公开消息与工具结果；Timeline 可按项目/轮次/Agent切换。Task、Issue、Evidence 作为工作台标签/抽屉，不需要新增 Shell 子命令。

宽度<100列：单主区+可切换角色；100–159列：主区+一个详情区；≥160列允许三列。阈值为初值，必须用TestBackend/PTY验证。布局调整不导致后台执行变化，不丢失展开和滚动锚点。

每块有稳定 block_id：message、task、tool、diff、test、evidence、decision、handoff。展开不会重新运行任务。长内容分页加载，可复制纯文本；Escape返回，保留选中项。只显示公开输出与简要决策理由，不伪造/索取模型隐藏推理。

## Timeline 与可置信进度

事件示例：10:30 Commander→Developer 派发；10:40 Candidate frozen；10:41 QA/Review并行；10:45 Issue opened；10:46 Commander决定修复。点击展示消息、版本和证据引用。

重要事件使用Runtime确定数据；模型摘要注明是分析。`Agent process alive` 不展示成“正在思考”；显示工具运行/等待服务/压缩/排队/空闲/最近活动时间。Commander空闲时写“事件监测中”，不伪装持续推理。

需求修改后分母会变化：展示 spec revision，新增/删除范围单独标记。失效验收从当前已验收计数扣除，保留历史。禁止把Task done比例叫产品完成度。

## 输入路由

普通输入默认给Commander。@role是稳定目标；@Claude有多个职位时以当前任务角色解析并显示实际目标，含糊则选择器。Ask走只读查询；Steer记录当前attempt及checkpoint；Change写CR；Control走运行时。用户新消息有queued/delivered/applied/rejected四态，失败可追踪，不能显示“已下令”实际丢失。

## 键盘与终端

Shift+Tab循环模式（配置可改）；Enter只在输入编辑器发送，在列表打开；Tab补全或移焦；Esc关闭临时层而非取消工作。Ctrl+P打开命令面板，可重绑。Ctrl+C在非空编辑器清空/取消编辑；空闲顶层第一次显示“脱离 / 暂停 / 取消任务”选择。SIGTERM需恢复终端且仅关闭客户端，显式cancel才杀子进程。

Ctrl+R保留输入历史搜索；恢复历史run放/resume，避免前文冲突。快捷键只在相应focus scope生效，输入?时不能全局劫持为帮助。支持bracketed paste；不支持增强键盘协议时使用Ctrl+J或Esc+Enter多行，不假定Shift+Enter所有终端可用。

中文宽字符按grapheme/显示宽度计算，不用字节长度。NO_COLOR、无鼠标、ASCII图标回退。panic/unwind/正常退出均恢复raw/alternate screen；鼠标点击为增强，不是唯一通道。借鉴终端alternate screen机制 [S24]，具体键位均为HoH自己的设计。

## Web

页面：Overview、Specs、Team、Timeline、Quality、History、Settings。执行状态与TUI同一投影；写操作携带expected_revision/idempotency_key。断线显示stale与最后event序号；重连后先补历史再继续live。默认loopback访问，远程通过SSH端口转发，不为VM应用增加复杂多租户权限系统；但每个请求都要携带host启动时生成的本地token，并校验Host/Origin为绑定的loopback地址，防止浏览器跨站请求与DNS rebinding（`contracts/openapi.json`）。

关键流程：修改角色→diff→安排checkpoint交接；修改Prompt→预览合成→创建revision→仅下个attempt使用；版本过期写入返回冲突，不悄悄覆盖。
