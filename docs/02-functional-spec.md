规范状态：待实现。ID唯一对应 `contracts/requirements.json`。每项要求成功路径、失败路径与可观察证据；禁止将实现占位当完成功能。

## REQ-001 · 默认交互入口

阶段 M1 · P0 · v1必需。

**场景：** 在有 TTY 的目录执行 hoh。

**必须行为：** 进入 Workspace，保留输入历史与工程状态，不新增任务直到用户提交意图。

**边界：** 缺失输入/依赖或版本冲突时返回明确错误并保持上次已提交状态；不自动把失败变成成功。该功能的特定错误语义见接口、恢复和适配器文档。

**验收 AC-001 / TEST-001：** PTY 启动、退出、恢复终端属性。保存输入、命令/事件、实际输出、版本与判定；未执行标 NOT_RUN。
